# 独立算法重实现 · 第一批

本批是可编译的独立 Java 数学模块，不调用 JNI、不读取 SDK 授权、不加载原版 SO。它尚未组成完整挖机求解器，也未切换施工界面的计算引擎。现有平面演示和原库接口继续保留原有含义。

实现：`app/src/main/java/com/rea/wajibao/replica/recovered/RecoveredMath.java`。

| 能力 | 保留的恢复行为 |
|---|---|
| 距离、点积、叉积、尺度比 | 单精度几何；尺度分母须大于 1e-6 |
| 角度归一化 | (-180, 180]，-180 转为 +180 |
| X/Y/Z 轴旋转 | 输入单位为度，保持单精度中间正余弦 |
| 四点平面法向 | 比较 abc、bcd、abd、acd 四个三角形；严格大于才替换；平方模不大于 1e-12 时保留原向量 |
| XYZ 基向量转欧拉角 | 输出度，含正负 90 度奇异分支 |
| 四元数乘法、共轭、归一化、旋转 | 分量顺序 w,x,y,z；旋转函数不暗中归一化输入 |
| IMU ↔ NEU | 输入角为弧度；先翻转局部 Z，再按四元数旋转和平移；逆变换对称处理 |
| 三角面高程 | 支持平面外插；XY 行列式精确为零时返回 0，调用者须另行判定退化面有效性 |

## 证据与边界

`reference/recovered/evidence/` 保存先前从原库恢复的 23 个带类型伪代码文件；`symbols.tsv` 记录原始 ELF 地址与符号。伪代码不是厂商源码，也不是可直接编译的实现。原库 SHA-256 为 `443a89c357df2277ea3e604db699188fc0b52eba3cd2306332f4e544b49bfa32`。

Java 从先前独立 C++ 转写 `reference/recovered/recovered_math.hpp` 移植而来。为防止非法输入，新实现增加有限数检查和无效四元数异常。归一化使用余数取代原生反复加减循环，避免极大角度阻塞；普通角度保持约定，但极端浮点输入不承诺与原循环逐位一致。超出常规工程数量级的溢出也不在数值等价承诺范围内。

模块不猜测 32 个机械参数如何组合，不把 GNSS 高程当作真实铰点，不替代十种机械模式、安装侧补偿、标定和附件连杆解算。

## 验证

`RecoveredMathTest` 包含四组测试：单位和边界、三轴旋转与欧拉奇异分支、平面选择和退化行为、128 组 C++ 坐标变换样本及逆变换。大地坐标原点为北坐标 3844277.123、东坐标 474561.456、高程 75.789，Java/C++ 比较与回环容差均为 1e-8 米。

样本是独立 C++ 转写的交叉语言回归基准，不是原版数值输出，因此不能证明原版算法等价。复现样本：

```bash
c++ -std=c++17 -O2 reference/recovered/generate-fixtures.cpp -o /tmp/wjb-fixtures
/tmp/wjb-fixtures > app/src/test/resources/recovered-imu.tsv
./scripts/build-cloud.sh :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

下一阶段需要逐段恢复完整求解器的机械坐标链、天线至铰点偏移、安装侧及修正角，再构建有已知机械姿态和预期斗齿坐标的独立测试。原版在授权检查下的全零输出不能充当正确答案。
